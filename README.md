# EclipseNB GNSS Data Processing

## Project Overview
This repository contains scripts and utilities for the **EclipseNB GNSS project** under the **Radio Science and Plasma Laboratory (RSPL)** at the **University of New Brunswick (UNB)**. 

The primary goal is the recovery and processing of GNSS data (specifically from u-blox and Sptentrio receivers) to support ionospheric physics research.

## Key Features
* **Data Recovery:** Automated scripts for handling 15-minute data blocks.
* **Format Conversion:** Integration with `gfzrnx` and `RTKLIB` `RNX2CRX`for RINEX processing.

## Technical Environment
* **OS:** Debian (WSL)
* **Tools:** `gfzrnx`, `convbin`, `gzip`
* **Language:** Bas
